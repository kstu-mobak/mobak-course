# Как сдавать задания по МОБАК на GitHub

Теория, схемы, разборы, вопросы и ручные задачи — на [сайте курса](https://kstu-mobak.github.io/mobak-course/). Задачи на программирование сдаются через GitHub: после каждой отправки GitHub сам проверяет код и ставит баллы.

## 1. Один раз: аккаунт GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно). Имя пользователя выберите понятное, например `ivanov-ivan`.
2. Откройте ссылку-приглашение на задание недели от преподавателя.
3. Если попросят, выберите себя в списке группы и нажмите **Accept this assignment**.
4. Через полминуты появится ссылка на **ваш личный репозиторий** — копию задания, которую видите только вы и преподаватель. Сохраните её.

На каждую неделю — своё приглашение и свой репозиторий.

## 2. Решаем прямо в браузере (ничего не нужно устанавливать)

1. Откройте свой репозиторий. Задачи лежат в папке `tasks/`, условия — в описании под списком файлов (README).
2. Откройте файл задачи, например `tasks/02_lr2_1_gcd.py`, и нажмите ✏️ (**Edit this file**).
   Удобнее — нажать клавишу **.** (точка): откроется полноценный редактор кода в браузере.
3. Напишите решение вместо заготовки (`pass` или комментария).
4. Нажмите **Commit changes…** → **Commit changes**. В редакторе по клавише «.»: значок ветки слева → **Commit & Push**.
5. Через 1–2 минуты откройте вкладку **Actions** → верхний запуск → **run-autograding-tests**. У каждой задачи:
   - ✅ — задача решена, баллы засчитаны;
   - ❌ — разверните шаг: там номер теста, что ожидалось, что получилось и строка вашего кода с ошибкой.
6. Исправляйте и отправляйте снова — сколько угодно раз до срока. Засчитывается последняя отправка.

Чтобы попробовать код перед отправкой, вставьте его в онлайн-редактор [Programiz](https://www.programiz.com/python-programming/online-compiler/) или [OnlineGDB](https://www.onlinegdb.com/online_python_compiler) и проверьте на примерах из условия.

## 3. Или решаем на своём компьютере

Нужны Python 3.8+ и Git ([git-scm.com](https://git-scm.com)). IDE — Thonny, VS Code или PyCharm.

```
git clone ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ
cd имя-репозитория
```

Пишите решение в файлах `tasks/…`, проверяйте той же проверкой, что и GitHub:

```
python tests/run.py        # все задачи недели
python tests/run.py 3      # только задача №3
```

Когда готово — отправьте:

```
git add tasks
git commit -m "Решил задачи 1–3"
git push
```

При первом `git push` Git попросит войти в GitHub — войдите через браузер.

## 4. Правила

- Не переименовывайте файлы и функции из заготовок — проверка ищет их по имени.
- Не меняйте папки `tests/` и `.github/` — преподаватель видит такие изменения, и работа не засчитывается.
- Соблюдайте ограничения из условия (например, в ЛР-2 нельзя `math.gcd`) — проверка их тоже проверяет.
- Задачи ⭐ дают дополнительные баллы.
- Любое решение может быть проверено устно (2–3 минуты): будьте готовы объяснить свой код строка за строкой.

## 5. Если что-то не так

- **Вкладки Actions нет или запуск не начался** — подождите минуту и обновите страницу; запуск начинается после каждого коммита.
- **«Файл не запускается»** — в коде синтаксическая ошибка; строка указана в сообщении.
- **«функция вернула None»** — вы не дописали `return`.
- **«Превышено время»** — бесконечный цикл или лишний `input()` в задаче-функции.
- Не получается — прочитайте подсказки к задаче (в README и на сайте курса) или спросите на паре.
